# 002 · Araçlar ve lisans

Kabul edildi. React 19, TypeScript 6 strict, Vite 8, Dexie 4 ve Zod 4 seçildi. Vitest 5 ile saf alan kuralları, Playwright ile iki dilin gerçek tarayıcı akışı doğrulanır. CSS ve React yerel durumu ilk çalışma döngüsünü karşılar. Router, global durum, sunucu önbelleği ve bileşen kütüphanesi, ilgili kullanım ihtiyacı oluştuğunda değerlendirilecek.

React ve Vite sürüm belgeleri, Vitest çalışma gereksinimleri ve npm paket motor/peer sınırları kontrol edildi. Kilit dosyası kurulumda test edilen sürümleri sabitler. Node alt sınırı ESLint 10’un gereksinimiyle 22.13’tür. [React sürümleri](https://react.dev/versions) · [Vite sürümleri](https://vite.dev/releases) · [Vitest başlangıç kılavuzu](https://vitest.dev/guide/)

MIT seçildi. Kod ve özgün içerik için yeniden kullanım ve katkı koşulları hafiftir. Telif ve lisans metni yeniden dağıtımda korunur. Dış içerik katkılarının kaynak ve lisansı ayrıca incelenir.
