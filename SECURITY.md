# Güvenlik bildirimi

Güvenlik açığını proje bakımcılarına özel olarak bildir. GitHub’da özel güvenlik bildirimi etkin olduğunda Security sekmesini kullan. Etkin değilse bakımcının yayımladığı özel kanalı kullan. Yeniden üretim adımları, etkilenen sürüm ve olası etkiyi paylaş. Gerçek kullanıcı yedeği, oturum alıntısı veya erişim bilgisi ekleme.

İlk sürümde veriler tarayıcıda kalır. Dışa aktarılan JSON, kullanıcının yanıtlarını ve içe aktardığı konuşma örneklerini içerir. İçerik paketleri ve konuşma raporları uygulamaya alınırken şemaları doğrulanır.
